# Before You Go · 出門看看

Compare two or three Taiwan destinations using live scenic cameras and nearby Central Weather Administration observations. The English and Traditional Chinese picker groups 21 destinations into waterfronts and old streets, lakes and countryside, and coastal views.

## Run locally

Extract the repository archive first. On macOS, double-click **Start Before You Go.command** with Python 3 installed. Alternatively, run `python3 start.py` in the project folder. Keep the terminal open while viewing. The launcher serves the project only on your computer and opens the app in your browser.

Opening index.html directly provides camera links. Side-by-side YouTube players need an HTTP or HTTPS page. Streams and weather require internet access. Every card links to its source and shows the observation time when available.

## Catalog

The destination names, viewpoints, broadcaster credits, source links, video IDs and weather station IDs are in `catalog.js`. If a broadcaster restarts a stream with a new ID, use the source link to identify the current broadcast. The picker artwork is illustrative.
